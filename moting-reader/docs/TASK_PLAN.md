# 墨听阅读器：完整任务规划

## 1. 产品目标

做一款个人使用、移动端优先、可安装的本地 PWA 阅读器。用户导入电子书后，可以阅读，也可以进入独立的“听书”界面选择书籍并连续朗读。

软件必须满足：

- 不登录也能使用。
- 不依赖 API Key 也能完成导入、阅读和系统语音朗读。
- 数据默认保存在当前浏览器中。
- 阅读位置和听书位置分别记录，并支持从当前正文位置开始听。
- 最终交付本地源码和使用说明压缩包，不进行线上部署。

## 2. 本次交付范围

### 2.1 书架

- 导入 EPUB、文字型 PDF、TXT、Markdown。
- 展示封面、书名、作者、格式、阅读进度和最近打开时间。
- 搜索、排序、删除书籍。
- 继续阅读。
- 显示导入、解析和错误状态。

### 2.2 独立听书页

- 继续上次收听。
- 浏览全部可听书籍。
- 搜索和筛选最近收听的书籍。
- 显示收听进度、当前章节和语音状态。
- 从列表直接进入播放器。

### 2.3 阅读页

- 章节目录。
- 上下章切换。
- 字号、行距、页边距、字体与主题设置。
- 当前朗读句高亮。
- 从任意句子开始朗读。
- 添加书签或听书标记。
- 阅读进度自动保存。

### 2.4 听书播放器

- 播放、暂停、前后一句。
- 上下章切换。
- 倍速。
- 语音选择。
- 睡眠定时。
- 查看当前文字。
- 逐句高亮和自动滚动。
- 听书位置自动保存。
- 一键标记当前句。

### 2.5 笔记与设置

- 汇总阅读书签和听书标记。
- 点击标记回到对应正文。
- 管理默认语音、倍速、主题和阅读排版。
- 查看本地数据说明。
- 清空演示内容或全部本地数据。

## 3. 核心数据模型

```text
Book
├── Chapter
│   ├── Paragraph
│   │   └── Sentence
│   └── ...
├── readingPosition
├── listeningPosition
└── metadata
```

关键原则：

- 原始展示文本和可朗读文本分开处理，但映射到同一句 ID。
- 阅读位置与听书位置分别保存，避免两种使用方式互相覆盖。
- 所有书签绑定稳定的书籍、章节和句子 ID。
- 语音按句子顺序播放，以句子边界作为暂停和跳转单位。

## 4. 文件导入策略

### EPUB

- 读取容器文件和 OPF。
- 提取 metadata、spine、封面和正文。
- 按书籍原有顺序生成章节。
- 清除脚本、样式、页眉页脚等不可朗读内容。

### 文字型 PDF

- 按页提取文本。
- 合并同一段落的断行。
- 清除纯页码和高频重复页眉页脚。
- 尝试识别章节标题。

### TXT / Markdown

- 使用文件名或首个标题作为书名。
- 识别 Markdown 标题和“第 X 章”样式。
- 没有目录时按文本长度安全分章。

### 本次不承诺

- 扫描 PDF OCR。
- DRM 保护的 EPUB。
- 复杂公式、双栏论文和高度定制排版的完全还原。

## 5. 听书实现策略

默认使用浏览器/系统提供的 Speech Synthesis：

- 无需账号和 API Key。
- 按句子创建朗读队列。
- 通过当前句索引实现逐句高亮、跳转和断点续播。
- 倍速在播放阶段调整。
- 语音列表由当前设备提供。

代码中保持语音服务边界，未来可以增加云端高质量 TTS，但本次交付不嵌入密钥，也不让用户在前端暴露密钥。

## 6. 本地存储

使用 IndexedDB 保存：

- 解析后的书籍和章节。
- 阅读位置与听书位置。
- 书签和听书标记。
- 用户设置。

原始文件不会上传到服务器。删除书籍时同步删除其内容和相关标记。

## 7. 视觉和交互标准

- 米白纸张背景、深墨色文字、灰蓝单一强调色。
- 正文使用适合中文阅读的系统衬线字体。
- 控件使用系统无衬线字体。
- 避免卡片堆叠、渐变、玻璃效果和装饰性 AI 元素。
- 移动端底部一级导航：书架、听书、笔记、我的。
- 所有高频触控区域不小于 44px。
- 支持 iPhone 安全区和桌面响应式布局。

## 8. 异常与边界状态

- 文件类型不支持。
- 文件过大或解析失败。
- EPUB 无目录或无封面。
- PDF 只有扫描图像。
- 当前设备没有可用语音。
- 朗读被系统中断。
- 删除正在播放的书籍。
- 当前章节为空。
- 浏览器存储不可用或空间不足。

每一种异常都必须给出用户可理解的状态，不显示底层技术错误。

## 9. 验收标准

- 示例书和用户导入书都能进入书架。
- EPUB、文字 PDF、TXT/Markdown 至少各有一条受测路径。
- 刷新页面后，书籍、进度、标记和设置仍然存在。
- 阅读与听书分别恢复到各自位置。
- 从正文任意句开始听时，播放器定位到同一句。
- 播放时当前句高亮，前后句控制准确。
- 修改倍速和语音后下一句生效。
- 定时关闭能够停止朗读。
- PWA manifest 和离线外壳可用。
- TypeScript、生产构建和项目测试全部通过。
- ZIP 中包含源码、安装说明、任务规划、测试记录和已知限制。

## 10. 实施顺序

1. 工程和数据模型。
2. IndexedDB 本地存储。
3. 文本、EPUB 和 PDF 解析。
4. 书架与导入流程。
5. 阅读页。
6. 独立听书页和播放器。
7. 笔记与设置。
8. PWA 和离线外壳。
9. 异常状态、响应式和可访问性。
10. 构建、测试、视觉检查、文档和打包。
