# 发现书籍

## 目标与使用场景

用户在已有本地书库中浏览中外图书的公开书目信息，看到感兴趣的书后，一步跳到现有「在线找书」并自动按书名搜索。发现页只展示书目，不承诺在线书源有对应文件。

## 核心流程与范围

1. 进入「书库 → 发现书籍」，默认展示文学分类。可切换文学、悬疑、科幻、奇幻、历史、传记、心理、旅行分类，也可提交书名或作者关键词。
2. 可按「全部／中文／英文」版本语言筛选；「全部」优先展示中文版本，但保留其他语言作品。语言表示 Open Library 收录了相应版本，不表示作者国别或原著语言。
3. 书籍卡片显示封面、书名、作者和首次出版年份；缺失字段明确显示占位信息。点击卡片按需读取简介和主题，提供 Open Library 原始资料链接。
4. 点击「找这本书」进入现有「在线找书」，填入所选书名并自动搜索；后续登录、选择格式、下载和入库继续沿用既有流程。

本次不增加推荐算法、评分、购书支付、云端个人书架或第二个书源。书目只在用户进入发现页、切换分类/语言、提交搜索和打开详情时请求，不批量采集。

## 数据来源与方案依据

- [Open Library Search API](https://openlibrary.org/dev/docs/api/search)：按分类与关键词查作品，读取优先版本的书名及封面；`language:chi` / `language:eng` 用于版本过滤，`lang` 仅用于优先显示。
- [Works API](https://openlibrary.org/dev/docs/api/books)：打开单本书时读取简介和主题。
- [Covers API](https://openlibrary.org/dev/docs/api/covers)：按封面 ID 直接展示封面，不复制或批量下载。
- [API 使用规范](https://openlibrary.org/developers/api)：面向真实用户、按需请求、缓存结果。当前请求附应用名和仓库 URL；未设置联系邮箱，按未标识请求的默认限流设计。若使用量增长，应提供联系邮箱并重新评估限流。

同源 Cloudflare Worker 固定转发到 Open Library，校验分类、页码、语言和作品 ID，限制响应大小与超时，成功结果缓存 30 分钟。PWA Service Worker 不拦截 `/api/`，避免将发现页结果永久固定在设备缓存。没有增加依赖或新服务。

## 验收与验证

| 前提 | 用户操作 | 可观察结果 |
| --- | --- | --- |
| 网络可用，进入书库 | 点击「发现书籍」并切换分类/版本语言 | 出现对应公开书目卡片，可加载更多 |
| 已有书目卡片 | 打开卡片 | 显示书名、作者、年份、简介或明确的缺失提示，以及原始资料链接 |
| 已打开详情 | 点击「找这本书」 | 进入「在线找书」，搜索框为该书书名，自动发出搜索请求 |
| 搜索无结果或上游失败 | 提交搜索或切换分类 | 显示空状态或错误与重试入口，不编造书籍 |
| iPhone 宽度 375、390、430 像素 | 浏览列表、详情与切换栏 | 无横向溢出，按钮可触达，底部导航保持可用 |

接口单元测试覆盖版本书名、缺失字段、非法输入、上游限流/格式异常和过大响应。浏览器夹具测试覆盖分类、语言、分页、详情、跳转自动搜索、空结果、错误重试及视口；夹具不代表真实 Open Library 可达。

2026-09-22 本地验证：`npm test` 完成生产构建与 116 项测试；`npm run typecheck`、本次改动的 ESLint、Wrangler 上传预检均通过。`tests/discovery-browser.py` 与 `tests/online-library-browser.py` 均通过；前者检查 375 / 390 / 430 / 768 像素视口和发现到自动搜索，后者检查既有在线找书、测试 EPUB 入库及刷新后的重复识别。浏览器测试使用明确标注的接口夹具，截图保存在忽略目录 `.wrangler/discovery-tests/`。

同日功能提交 `d9355cf` 已推送至 `origin/master`。原账户因本地 `CLOUDFLARE_ACCOUNT_ID` 与 Token 所属账户不一致而拒绝发布；按用户后续指示，改在该 Token 所属账户创建 `moting-reader` Worker。Cloudflare 确认 100% 流量运行版本 `25142c62-c498-445d-8192-9444238f6415`，地址为 https://moting-reader.if5v.workers.dev 。原账户的 Worker 未被修改。

当前设备对 `workers.dev` 的 DNS 也返回异常地址，访问新域名超时；Cloudflare 远程预览本地通道同样超时。因此线上页面和真实 Open Library 搜索尚未完成实际操作验收。后续可在正常网络中检查「发现书籍 → 分类 → 详情 → 找这本书」及书目接口响应。
