# 推荐与榜单轮换

## 已确认目标

用户所说“新书”是自己没见过的书，包括旧书。2026-10-21 确认实施：曝光记录、候选轮换、首页榜单轮换，保持同次浏览的内容与位置稳定。

## 范围与约束

- 基于 GitHub master da7f7c5，复用现有 11 类静态书目、封面、阅读记录与界面。
- 主页与书城共用推荐。从整个候选池选取，按实际阅读与点击给予兴趣权重，限制单一题材和作者占比。
- 卡片可见面积至少一半且停留 800ms 才记曝光；隐藏页面、后台和预取不算。相同作品一天一次，近期曝光降权，候选充足时先选未展示作品。
- 排除本地已入库作品，按作品书名、作者归一以减少重复版本。详情的“不感兴趣”可撤销。
- 推荐快照按本地日期轮换；同日返回、刷新保持当前批次，主动换批跳过当前批次。
- 口碑、热读、小众口碑三种榜单按实际字段计算。首页每天轮换分类与展示区段，可主动换榜；卡片名次对应完整榜。书城支持切榜、换组和完整榜单。
- 页面保留现有软白、宣纸、墨夜主题与排版；不改变听书、阅读、同步、AI、部署资源绑定。
- 曝光和反馈只存当前设备；存储不可用时记录内存降级。源失败显示实际状态，不伪造评分或热度。

## 验收

- 真实书池连续选择 20 批，记录已展示作品后不重复；同时验证版本去重、已入库排除和题材多样性。
- 推荐入口共享当前批次；换批不新增上游请求；跨日产生不同结果。
- 手机视口 375、390、430px：横滑曝光准确、隐藏页不记曝光、返回批次与滚动稳定、详情反馈可撤销。
- 三种榜单的顺序与实际字段一致；首页更深区段展示原始名次；完整榜从第1名开始。
- 类型检查、lint、完整测试与构建、Cloudflare 产物预检通过后提交部署。

## 不在本次范围

近期出版优先、新的书源、定时采集、协同过滤服务、云端行为画像。后续扩充书池可以独立进行。

- 0f9d30d：持久快照用于避免首页布局跳动与返回时重建。
